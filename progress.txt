# Codebase Patterns

- **CSS:** All design tokens in :root variables (--color-*, --spacing-*, --radius-*, --transition-*)
- **JS:** IIFE pattern, strict mode, state object for form data
- **HTML:** Semantic sections with .screen class, data-screen attribute, aria-label
- **Naming:** BEM-style CSS (block__element--modifier)
- **Screens:** Each screen is a <section class="screen"> with data-screen="N"
- **Navigation:** goToScreen(index) handles transitions + progress bar updates
- **Progress:** Calculated as (currentScreen / TOTAL_STEPS) * 100
